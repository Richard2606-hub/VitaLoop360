# Data provenance and disclosure

VitaLoop 360 is a local demonstration based on `01_VitaLoop360_Proposal.docx`, supplied in the parent workspace. Lumora Wellness is a fictional company. Lots, production records, people, suppliers, orders, customer contexts, and care check-ins in the application are authored demonstration material.

## What is included

| Material | Origin and intended use |
| --- | --- |
| Factory telemetry and baselines | Synthetic sample values authored for this prototype. They are not measurements from a plant or a public dataset. |
| Factory calculations | Deterministic code applied to the synthetic values. Calculated values are real calculations of fictional inputs. |
| Procedures and care instruction excerpts | Authored fictional source text for demonstrating citations and version binding. They have not been approved by a manufacturer or clinician. |
| Orders, planning, experience, and care views | Authored scenario walkthroughs explaining the proposed cross-department flow. They are not evidence of connected external systems. |
| Model text without configured inference | Authored deterministic demonstration output. It is not a recording of an AMD/Gemma completion. |
| Runtime model response, if enabled | Output from the operator-configured endpoint. Endpoint naming alone does not independently verify its hardware. |
| Local audit records | Records produced by actions in this local instance. They are not historical evidence of real production decisions. |

## What is not included

No UCI Steel Industry Energy Consumption, AI4I, Online Retail II, SROIE, CORD, CUAD, or review dataset has been downloaded or incorporated into this build. The proposal's dataset names are a future data plan, not a description of these samples. Their licenses, attribution obligations, and suitability must be checked before later use or redistribution.

No real patient records, operational plant records, supplier credentials, or production customer data were provided. Do not enter such data into this local prototype. If a model endpoint is configured, prompt content is sent to that endpoint under its operator's policies.

## Financial and performance figures

Factory savings are estimates from displayed assumptions, not demonstrated cost reductions. Model spend is an estimate only when provider-reported token usage and operator-configured token prices are available. Unset prices cannot establish a real cost of zero. Walkthrough business values are scenario assumptions.

Request latency measures this application's round trip to an endpoint. It does not establish GPU throughput, hardware utilization, or production service guarantees. No external pricing, provider availability, hackathon rule, model license, or prize eligibility claim has been independently verified as part of this implementation.

## Implementation lineage

The supplied proposal describes conceptual lineage from GuildHouse, RouteWiser, and FourCast. No implementation from those projects was supplied for this build or intentionally imported. The local implementation is newly authored from the supplied proposal. This disclosure does not assert the originality or legal status of upstream concepts.

## Before replacing the samples

Record each source's owner, license, version, extraction date, mapping, and limitations. Preserve the distinction between observations, inferred quantities, proxies, and assumptions. Review documentation for the exact product and lot before connecting any operational or caregiver flow. Obtain applicable privacy and security review before using real personal information.
